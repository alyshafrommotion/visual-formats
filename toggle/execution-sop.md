# Toggle Format — Implementation SOP

## Reference examples (look here first)

They sit in this same folder, next to this SOP. **Open the folder and study the example first** — the toggle UI styling, the off-vs-on framing, and the background photo.

## What this format is

A static (or video) that overlays an iOS-style settings toggle/switch on a photo (often a mirror selfie): one option switched off, the brand option switched on. It works because the familiar UI is an instant, native-feeling pattern interrupt that frames the decision as a simple flip.

Strongest for **habit/goal framing, swap-this-for-that positioning, and lifestyle-selfie UGC.**

The one property to protect: **the toggle UI has to read as authentic** and the off/on contrast must be instantly clear.

## Inputs

Expect a **messaging angle**, the off option (the bad habit/alternative), the on option (the brand), and a background photo. The angle picks the contrast; this SOP governs the overlay.

## Anatomy

1. **The header:** a short framing line ("2025 fitness goal").
2. **The toggle rows:** the off option (switch off) + the brand option (switch on, green).
3. **The background photo:** lifestyle/mirror selfie with the product visible.

## Build rules (priority order)

1. **Authentic toggle UI.** Match the real settings-switch look; green = on.
2. **One off, one on.** Keep the contrast to a single clear pair (2–3 rows max).
3. **Product visible** in the background photo.
4. **Short header** that frames the choice.
5. **Legible overlay at thumb size.**
6. **Real, specific claims. No absolutes / banned phrases.**

## Length caps

| Element | Cap |
|---|---|
| Header | ≤5 words |
| Toggle rows | 2–3 |
| Row label | ≤4 words |

## Build steps

1. Read the brief: angle, the off option, the on (brand) option.
2. Write the header framing line.
3. Build the toggle rows (off vs on, green for the brand).
4. Choose a background photo with the product visible.
5. Place the overlay legibly.
6. Claims pass (real, specific; validate numbers).
7. Legibility check at thumb size.
8. Deliver: header, toggle rows, background note, claims flags.

## QA checklist
- [ ] Toggle UI reads as authentic (green = on)
- [ ] One clear off-vs-on pair (2–3 rows)
- [ ] Product visible in the photo; overlay legible at thumb size
- [ ] Claims specific and validated; no absolutes/banned phrases
