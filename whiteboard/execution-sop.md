# Whiteboard Format — Implementation SOP

## Reference examples (look here first)

They sit in this same folder, next to this SOP. **Open the folder and study the example first** — the marker handwriting, the rough doodles, and how homemade it reads.

## What this format is

A static (or video) built to look like a real dry-erase whiteboard: the message handwritten in marker, often with a rough drawn comparison (crossed-out competitor vs a checkmarked product), the board propped in a real setting like a kitchen counter. It works because the low-fi, homemade look reads as honest and un-adlike, and a hand-drawn argument feels like a friend explaining it.

Strongest for **simple comparisons, myth-busting, "here's the real difference," and founder/insider explainer energy.**

The one property to protect: **it has to feel genuinely handmade** — a too-clean digital "whiteboard" loses the effect.

## Inputs

Expect a **messaging angle** and the one simple argument or comparison to draw. The angle carries the message; this SOP governs the whiteboard staging.

## Anatomy

1. **The board:** a real dry-erase whiteboard, propped in a real setting.
2. **The handwritten hook:** the main line in marker at the top.
3. **The drawn argument:** a rough doodle comparison (crossed-out vs checkmarked) or a short marker list.
4. **The payoff line:** the takeaway in marker.

## Build rules (priority order)

1. **Genuinely handmade look.** Real marker, real board, real setting. Embrace imperfect handwriting.
2. **One simple argument.** A comparison or a single point — not a dense essay.
3. **Use the crossed-out vs checkmark device** when contrasting; it reads instantly.
4. **Legible handwriting at thumb size.**
5. **Keep it low-fi** — the charm is that it isn't polished.
6. **Specific, real claims. No absolutes / banned phrases.**

## Length caps

| Element | Cap |
|---|---|
| Hook line | ≤10 words |
| Drawn comparison | 2 items (vs) |
| Payoff line | ≤2 short lines |

## Build steps

1. Read the brief: angle, the one comparison/point.
2. Write the marker hook.
3. Sketch the drawn argument (crossed-out competitor vs checkmarked product, or a short list).
4. Add the payoff line.
5. Stage the board in a real setting; shoot/mock it low-fi.
6. Claims pass (real, specific; validate numbers).
7. Legibility check at thumb size.
8. Deliver: hook, drawn argument, payoff, staging note, claims flags.

## QA checklist
- [ ] Reads as a genuinely handmade whiteboard in a real setting
- [ ] One simple argument/comparison, handwriting legible at thumb size
- [ ] Crossed-out vs checkmark used where contrasting
- [ ] Claims specific and validated; no absolutes/banned phrases
