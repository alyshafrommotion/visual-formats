# Graphic Anchor Format — Execution SOP

For "is this ad a Graphic Anchor?" naming/classification questions, use `classification.md` in this same folder instead. This document is for building and scripting one.

## Reference examples (look here first)

Example media lives in the shared `../files/` store, matched by the format token: all Graphic Anchor examples are files containing `vf=graphic-anchor`. **Start with `c=oren-john_vf=graphic-anchor.mp4`** and watch how each graphic enters on the beat it supports and swaps as the point changes.

## What this format is

A creator talks directly to camera and carries the ad; graphics (screenshots, UI, cards, icons, product shots, metaphor props, b-roll) pop up **around** them, layered over the same shot, to make each point land harder. It is **always a video**. The creator is the anchor; the graphics are the rotating support layer.

Strongest for: **explainers, "here's how it works," teaching/list content, breaking an abstract concept into visible pieces, and stacking proof or examples faster than the VO alone could.**

The one property to protect: **the creator holds the frame, and every graphic earns its beat** by clarifying, emphasizing, visualizing, or extending the exact line it lands on. Never decorative wallpaper.

## Inputs

Expect a **messaging angle** (the point), persona and awareness stage, the **VO/script**, and a **graphics list**: for each beat, what visual supports it and which type it is (real evidence, literal visual, or metaphor). Real evidence (screenshots, UI, data) must be real and legible.

## Anatomy — the layers

### 1 · The creator (anchor)
- Talks to camera in a real setting, holds the frame throughout. Real, casual energy.
- Not composited in front of a full-frame screen (that would be greenscreen).

### 2 · The graphics layer
- Enters around/beside/above the creator, over the same shot.
- One graphic per idea; swaps when the point changes.
- Mix types to keep it alive: real UI/screenshots (clarify/prove), literal product/b-roll (visualize), metaphor props (make the abstract concrete).
- Legible at thumb size in ~1–2s.

### 3 · The script
- Written first. Each line gets exactly one supporting graphic.
- The graphic matches the words; pointing is optional.

## Script / build rules (priority order)

1. **Write the VO first,** then assign one graphic per beat.
2. **Every graphic earns its moment** — clarify, emphasize, visualize, or extend the line it lands on. Cut anything decorative.
3. **One idea, one graphic, then swap.** Momentum comes from graphics changing with the points.
4. **Vary the graphic type** across the ad so it doesn't feel like one gimmick (real UI, literal visual, metaphor, b-roll).
5. **Real evidence must be real,** sourced, and legible fast. No fabricated screenshots or data.
6. **Keep the creator the anchor** — graphics accent, they don't replace the shot.
7. **Brand/product enters as the payoff,** once, near the end (Oren: the $100 credits CTA).
8. **Banned:** decorative graphics that don't match the line, fabricated evidence, a full-frame background composite (that's greenscreen), absolutes.

## Length caps

| Element | Cap |
|---|---|
| Hook (creator + first graphic) | ≤3s |
| Beats | 3–8, each with its own graphic |
| Total runtime | 15–60s |
| Graphics per beat | 1 (occasionally a small cluster) |
| Brand mention | 1, as the payoff |

## Build steps

1. Read the brief: angle, persona, awareness stage.
2. Lock the VO/script; break it into beats.
3. For each beat, choose one graphic and label its type (evidence / literal / metaphor).
4. Verify any real evidence is real and legible.
5. Storyboard graphic entrances timed to the exact line each supports.
6. Place the brand as the payoff of the last beat.
7. Claims pass: every on-screen stat/quote sourced and validated.
8. Production handoff: creator holds frame, captions on, each graphic pops on its beat and clears when the point moves.
9. Deliver: VO by beat, the graphic + type per beat, brand payoff line, sources/claims flags, and a secondary format tag if one applies (e.g. listicle).

## QA checklist
- [ ] It's a video; creator talks to camera and holds the frame
- [ ] Graphics pop up around them (not a full-frame background composite)
- [ ] Every graphic matches the exact line it lands on; none decorative
- [ ] One idea per beat; graphic swaps with the point
- [ ] Graphic types varied across the ad
- [ ] Real evidence sourced and legible; nothing fabricated
- [ ] Brand enters once, as the payoff
- [ ] Secondary format tagged if the ad also does something else (e.g. listicle)
- [ ] Plays legibly at thumb size
