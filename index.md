# Visual formats — index (shared)

This is the shared, promoted version of the Visual Formats library. All 13 formats from Alysha's personal context-engine copy were promoted here on 2026-08-28; her personal library folder now only holds an `assets/` staging area of untriaged format candidates that haven't been promoted yet.

**On 2026-08-28, `notes-app-listicle-over-lifestyle` was split into two separate atomic formats**, `notes-app` (the device: a recognizable Notes-app screenshot) and `listicle` (the structure: a sequential one-point-per-slide list), since they're independently reusable and an ad can use either alone or both together.

Each format folder carries **two distinct documents**, use the right one for the job:
- **`classification.md`** — for naming an ad or auditing an existing one: how to tell whether an ad should be tagged as this format.
- **`execution-sop.md`** — for ideating, scripting, or briefing: how to build/write one correctly.

## How to use this library
- Naming/classifying an ad: open the format's `classification.md`.
- Ideating, writing a concept/script/brief: open the format's `execution-sop.md`.
- Study the example creatives in the folder alongside whichever doc you're using, they're calibration references pulled from real in-market ads (competitor and inspo swipe), not assets to copy verbatim.
- Every format here also has a matching row in the Notion Visual Format database with a `Brain Path` property pointing back to its folder here, see the Notion integration guide.
