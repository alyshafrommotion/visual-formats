# Statistic Format — Implementation SOP

## Reference examples (look here first)

They sit in this same folder, next to this SOP. **Open the folder and study the example first** — how big the number is, how it's supported, and how little else competes with it.

## What this format is

A static that leads with proof numbers rendered large over a product or lifestyle shot. It works because a concrete number is instantly credible and skimmable, and it does the "does this actually work?" job in one glance.

Strongest for **proof-hungry, mid-funnel audiences, results-driven products, and social proof / scale claims.**

The one property to protect: **the number is the hero and is legible in under a second.**

## Inputs

Expect a **messaging angle**, the **real stats** (with sources), and a product/lifestyle shot. The angle picks which proof leads; this SOP governs the layout.

## Anatomy

1. **The hero stat(s):** 1–3 big numbers, each a single clear proof point with a short label.
2. **The backdrop:** a product or lifestyle shot that gives context without fighting the number.
3. **The source footnote:** small citation grounding each stat.
4. **Brand + CTA.**

## Build rules (priority order)

1. **One glance, one number.** The stat must dominate; keep to 1–3.
2. **Each stat is a real, sourced proof point.** Footnote it. No invented figures.
3. **Label every number** so the proof is unambiguous ("94% saw less buildup").
4. **Backdrop supports, never competes** with the type.
5. **Legible at thumb size.**
6. **One CTA. No absolutes / banned phrases** ("designed to," "seamless").

## Length caps

| Element | Cap |
|---|---|
| Hero stats | 1–3 |
| Stat label | ≤6 words |
| Footnote | 1 short citation per stat |
| CTA | 1 |

## Build steps

1. Read the brief: angle, the stats, the source for each.
2. Pick the 1–3 strongest, sourced numbers.
3. Make each number huge with a short label.
4. Choose a backdrop that gives context without clutter.
5. Add source footnotes, brand, one CTA.
6. Claims pass (every stat sourced; numbers validated).
7. Legibility check at thumb size.
8. Deliver: stats + labels, sources, backdrop note, CTA, claims flags.

## QA checklist
- [ ] 1–3 numbers, each dominant and legible in a second
- [ ] Every stat labeled and sourced (footnote)
- [ ] Backdrop supports, doesn't compete
- [ ] One CTA; numbers validated; no absolutes/banned phrases
