# AI Generated Static Format — Implementation SOP

## Reference examples (look here first)

They sit in this same folder, next to this SOP. **Open the folder and study the example first** — the generated scene, the embraced AI look, and how copy is baked in.

## What this format is

A static that is an obviously AI-generated image — surreal/hyper-rendered, sometimes with warped text or odd details — with the message often generated right into the image. It works as a scroll-stopping novelty and lets you stage impossible or hyper-specific scenes cheaply.

Strongest for **playful/seasonal moments, surreal concepts, and bold thumb-stopping novelty** where a photoreal shoot isn't needed.

The one property to protect: **the concept and any on-image claim must still be clear and honest** even though the render is stylized.

## Inputs

Expect a **messaging angle** and a scene concept for the generator (prompt direction). The angle carries the message; this SOP governs the render.

> Note: this SOP directs the AI render (prompt/scene direction). Per house rules, provide the generation prompt and creative direction rather than generating the final image here.

## Anatomy

1. **The generated scene:** the hero AI image (concept-led, embraces the look).
2. **The baked-in message:** headline/copy rendered in or over the image.
3. **Brand + CTA.**

## Build rules (priority order)

1. **Concept-first.** The generated scene must serve one clear idea.
2. **Keep claims honest and legible**, even if styled — proof the on-image copy.
3. **Embrace the AI look** deliberately; don't pretend it's a real photo when it isn't.
4. **Brand clearly; one CTA.**
5. **Watch for garbled/embarrassing artifacts** on anything that must read cleanly (logo, key claim).
6. **No absolutes / banned phrases.**

## Length caps

| Element | Cap |
|---|---|
| On-image headline | ≤10 words |
| Claims | proof each |
| CTA | 1 |

## Build steps

1. Read the brief: angle, the scene concept.
2. Write the prompt/scene direction for the generator.
3. Specify the baked-in headline and where it sits.
4. Add brand and one CTA direction.
5. Claims pass (on-image copy honest; validate numbers).
6. Artifact check: key claim/logo legible, no embarrassing warps.
7. Deliver: generation prompt/direction, headline, brand/CTA, claims flags.

## QA checklist
- [ ] One clear concept driving the generated scene
- [ ] On-image claims honest, legible, proofed
- [ ] Brand clear; one CTA
- [ ] No garbled artifacts on key elements; no absolutes/banned phrases
