# Written On Body Format — Implementation SOP

## Reference examples (look here first)

They sit in this same folder, next to this SOP. **Open the folder and study the example first** — how the copy is written on the body and how the product sits in-shot.

## What this format is

A static where the ad's message is handwritten directly on a person's body — stomach, arm, skin — turning the body into the copy surface. It works as a pattern interrupt: the surprise of *where* the text sits stops the scroll, and it ties the message physically to the body/benefit.

Strongest for **body/health/supplement products, before-after or problem-agitation angles, and UGC-style feeds.**

The one property to protect: **the message reads as genuinely written on the body** (real marker, real skin), and the line is legible.

## Inputs

Expect a **messaging angle** and the one short line to write on the body. The angle carries the message; this SOP governs the placement.

## Anatomy

1. **The body canvas:** the relevant body area (stomach, arm) as the writing surface.
2. **The handwritten line:** the core message in marker, following the body.
3. **The product:** in-shot near the body.
4. **Optional disclaimer** ("individual results may vary").

## Build rules (priority order)

1. **Really write it on the body.** Real marker on skin; embrace the handmade look.
2. **One short line** that ties to the body/benefit.
3. **Legible** — follow the body's shape but keep it readable.
4. **Product in-shot.**
5. **Add a results disclaimer** where claims warrant it.
6. **Real, specific claims. No absolutes / banned phrases.**

## Length caps

| Element | Cap |
|---|---|
| Body line | ≤8 words |
| Disclaimer | 1 short line if needed |

## Build steps

1. Read the brief: angle, the one body line.
2. Write the line short and benefit-tied.
3. Choose the body area and write it on legibly.
4. Frame with the product in-shot.
5. Add a disclaimer if claims warrant.
6. Claims pass (real, specific; validate numbers).
7. Legibility check at thumb size.
8. Deliver: body line, body-area note, product placement, disclaimer, claims flags.

## QA checklist
- [ ] Message reads as genuinely written on the body (real marker/skin)
- [ ] One short, benefit-tied line, legible at thumb size
- [ ] Product in-shot; disclaimer where warranted
- [ ] Claims specific and validated; no absolutes/banned phrases
