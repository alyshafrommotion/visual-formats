# Greenscreen Format — Execution SOP

For "is this ad a Greenscreen?" naming/classification questions, use `classification.md` in this same folder instead. This document is for building and scripting one.

**Whenever this SOP is triggered or referenced, open this folder and watch the examples first** — how the greenscreen opens the hook, what's on the screen behind the creator, and whether they react to it directly or it just adds context (compare the Native Pet context-layer example with the more reactive ones).

## What this format is

A creator composited (greenscreened) in front of a full-frame background screen, telling you something the background relates to. It is **always a video**, and it **must open on the greenscreen in the hook** — that opening greenscreen is the anchor of the whole format, the way the comment sticker anchors a comment-response ad.

The background can work two ways:
- **React / reference:** the screen is evidence (a screenshot, headline, product page, review, chart, competitor site) and the creator reacts to and points at it. It feels like a friend showing you their phone.
- **Context layer:** the screen is imagery, a product, or a scene that adds context to what they're saying without being called out (e.g., talking about probiotic chews with dog chews on the screen behind them). The screen deepens the point rather than being the subject.

Either way there must be a **relationship** between what's on screen and what they're saying.

Greenscreen is usually the **anchor (primary)** format and often carries a **secondary** format tag (per the dual-format tagging rule), e.g. greenscreen + unboxing when an unboxing happens in the same video.

Strongest for **proof, myth-busting, comparisons, "look what I found," reframing an ingredient/claim, reacting to social/press, and layering product context onto a talking point.**

The one property to protect: **the hook opens on the greenscreen, and the background always relates to the talk** — never a random backdrop.

## Inputs

Expect a **messaging angle** (the point), persona and awareness stage, the **background asset(s)** (real evidence to react to, or the contextual imagery/product/scene), and claim facts. If the background is evidence, it must be real and sourced. The angle picks the point; the background relates to it; this SOP governs how the screen and the talk connect.

If the react version has no real evidence to show, get it. A greenscreen with a fabricated screenshot is a liability, not a format.

## Anatomy — the layers

### 1 · The background screen (opens the hook)
- Full-frame behind the creator from the first beat. This is the anchor: the video opens on it.
- React version: a screenshot/article/page/chart/review/comment, legible in ~1–2s (zoom/crop/highlight the one line that matters).
- Context version: product, scene, or imagery that reinforces the point (doesn't need to be acknowledged).
- One idea per beat; when the point changes, the screen can change.

### 2 · The creator (guide)
- Composited in front of the screen. Casual, real energy.
- React version: gestures at the screen, points, circles, zooms.
- Context version: talks to camera while the screen adds the layer behind them.

### 3 · The script
- Opens on the greenscreen and the relationship to it.
- React version: react first ("okay this is wild"), then the point.
- Context version: make the point; let the background reinforce it.

## Script / build rules (priority order)

1. **Open on the greenscreen.** The first beat is the composited screen and the line that relates to it. If your hook could play with no greenscreen, it isn't this format.
2. **Keep the relationship live.** Whatever is on screen relates to what's being said, by direct reference or as a context layer. Never a random backdrop.
3. **React version: react, don't narrate.** Open on the reaction, then the evidence, then the point. Don't read the screen verbatim — say what it means.
4. **One idea, one screen, then move.** New point, new background. Momentum is the format.
5. **Point at it (react version).** Circle, highlight, zoom the exact line.
6. **Specificity is credibility.** Real sources, real numbers, real quotes on screen. Never fabricate evidence. No absolutes.
7. **Brand/product enters as the payoff,** once, near the end.
8. **Casual, low-effort look is a feature,** it's what makes it feel found (casual-disarm / effort-mismatch mechanic).
9. **Banned:** a hook with no greenscreen, reading the screen verbatim, fake screenshots, "trust me," "designed to," "seamless," absolutes.

## Length caps

| Element | Cap |
|---|---|
| Hook (opens on greenscreen) | ≤3s, ≤10 words |
| Beats | 3–6, each with its own on-screen background |
| Total runtime | 15–40s |
| Spoken lines | short, ≤15 words |
| Brand mention | 1, as the payoff |

## Build steps

1. Read the brief: angle, persona, awareness stage.
2. Decide the mode: react-to-evidence or context-layer (or a mix).
3. Gather the background asset(s); if evidence, verify each is real and legible.
4. Sequence 3–6 beats that build to the point; the first beat opens on the greenscreen.
5. Write the hook (greenscreen + the line that relates to it), then one line per beat.
6. React version: mark the exact highlight/zoom/circle per screen.
7. Place the brand as the payoff of the last beat.
8. Claims pass: every on-screen stat/quote sourced and validated.
9. Production handoff: creator cut-out in front of a full-frame background from the first frame, captions on, cuts synced to screen changes.
10. Deliver: background sequence (with highlights where used), VO script by beat, brand payoff line, sources/claims flags, and the secondary format tag if one applies.

## QA checklist
- [ ] It's a video, and the hook opens on the greenscreen (the anchor)
- [ ] The background relates to what's being said (direct reference or context layer), never random
- [ ] React version: creator reacts first and explains meaning, doesn't read the screen
- [ ] One idea per beat; background changes with the point
- [ ] Brand enters once, as the payoff
- [ ] React version: every on-screen stat/quote sourced; no fabricated evidence; no absolutes
- [ ] Secondary format tagged if the ad also does something else (e.g. unboxing)
- [ ] Plays legibly at thumb size
