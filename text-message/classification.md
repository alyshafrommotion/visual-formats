# Text Message — Classification Guide

## Definition

A static built as a **screenshot of a text / iMessage conversation**, where the pitch plays out as a back-and-forth chat — a friend recommending the brand, a funny payment request, a confession.

## The things that must all be true

1. **The creative is a messaging-app conversation** (chat bubbles, contact header).
2. **The story or pitch is told through the exchange.**
3. **It feels like a real screenshotted DM/SMS thread.**

## Quick test

Is the ad a phone text thread you "read over their shoulder"? If yes, Text Message.

## Commonly confused with

- **Comment-response / comment-screenshot:** social platform *comment* UI, not a private DM/SMS thread.
- **Notes-app:** a typed note screen, not chat bubbles.
- **Instagram-text-overlay:** native IG text over a photo.

## Signals

Blue/grey iMessage bubbles, contact name header, a payment/Venmo-style request, "just FYI this brand…", a photo shared in-thread.

Examples in the files folder:

- Atlas Coffee Club "$17 Request" stolen-coffee bit
- Grüns "Elma" recommending methylated vitamins
