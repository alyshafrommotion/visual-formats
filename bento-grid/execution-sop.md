# Bento Grid Format — Implementation SOP

## Reference examples (look here first)

They sit in the shared `../files/` store, matched by the `vf=bento-grid` token. **Study one first** — notice how the tiles are deliberately different yet locked to the same alignment, palette, and type.

## What this format is

A static built as a **modular tile / bento-box layout that mixes cropped images and text panels** into one composed frame. It works because a clean, curated, editorial composition signals quality and craft, and because varied tiles let one ad carry several messages (product, detail, lifestyle, proof) without feeling busy.

Strongest for **collection launches, brand-story and heritage, editorial / lookbook moments, and multi-message stories** that need more than one idea in a single frame.

The one property to protect: **clean, aligned, deliberately-varied tiles that read as one composed piece** — bento, not collage.

## Inputs

Expect a **mix of assets** — a hero product shot, macro/detail crops, lifestyle imagery — plus the **copy points** for the text tile(s). The messaging angle decides what each tile argues; this SOP governs the composition.

## Anatomy

1. **The tile grid:** often 2x2 / 2x3 with some merged or larger tiles for hierarchy.
2. **At least one text tile:** title, collection name, or bulleted proof points.
3. **Image tiles:** a deliberate mix of product, macro crop, and lifestyle.
4. **Unifiers:** one palette, one type system, consistent gutters tying the tiles together.

## Build rules (priority order)

1. **Vary the tiles on purpose** — product shot, macro crop, lifestyle, text — but keep alignment and gutters tight.
2. **Include at least one text tile** carrying the message (title, collection, or bullets).
3. **Unify with one palette and type system** so the varied tiles read as a single composition.
4. **Use tile size and merging for hierarchy** — a bigger hero tile, smaller supporting tiles.
5. **Crop images intentionally** to their tile; embrace the framing.
6. **Keep it clean and aligned.** If tiles overlap or scatter, it's a collage, not a bento-grid.
7. **Honest claims.** Validate any proof points; no absolutes or banned phrases.

## Spec caps

| Element | Guide |
|---|---|
| Tiles | ~3-6 (mix of sizes) |
| Text tiles | at least 1 (title or bullets) |
| Image tiles | mix of product / crop / lifestyle |
| Palette | one unifying palette + type system |

## Build steps

1. Read the brief: the messages to carry and the assets available (hero, crops, lifestyle, copy points).
2. Choose a tile grid and assign hierarchy (which tile is the hero).
3. Place image tiles with intentional crops; place the text tile(s) with the title or bullets.
4. Lock one palette and type system; tighten gutters and alignment.
5. Add the brand lockup.
6. Claims pass (validate proof points).
7. Deliver: tile layout, per-tile asset/crop spec, copy for text tiles, palette/type notes, claims flags.

## QA checklist
- [ ] Tiles are deliberately different (not an interchangeable product lineup)
- [ ] At least one text tile carries the message
- [ ] One palette and type system unify the composition
- [ ] Tile sizing creates a clear hero/supporting hierarchy
- [ ] Clean and aligned — bento, not collage; claims validated
