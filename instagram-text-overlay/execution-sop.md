# Instagram Text Overlay Format — Implementation SOP

## Reference examples (look here first)

- **Brain location:** `/agent/brain/2. ideation/visual-formats/instagram-text-overlay/`
- This SOP lives in that folder, so the example creatives sit next to it.

**Whenever this SOP is triggered or referenced, open that folder and study the examples first** — the exact IG type treatment used, where the text sits, and how organic vs promotional the copy reads.

## What this format is

An ad that wears Instagram's own text styling — the story/caption/"add text" look, the classic centered-caption placement, the native fonts and highlight boxes — over a photo or short clip. It works because it borrows the platform's native visual grammar, so the ad slips into the feed as content and gets read before the guard goes up. Distinct from a generic text-on-image static: the *specific* IG treatment is the disguise.

Strongest for **hook-led statements, relatable/POV lines, listy value in the caption, and top-of-funnel scroll-stoppers** where feeling native buys the read. Pairs well with UGC-style imagery.

The one property to protect: **both the styling and the copy must read Instagram-native** — the type looks like the app, and the words sound like a person's caption, not a headline.

## Inputs

Expect a **messaging angle** (the statement or hook), persona and moment, and VOC for phrasing. The angle sets the message; VOC gives it native voice; this SOP governs the IG styling and the copy register.

## Anatomy — the layers

### 1 · The image/clip (native base)
- A photo or short clip that looks shot-on-phone or UGC, not studio. It reads as someone's post.

### 2 · The IG text treatment (the format)
- Use Instagram's own text conventions: the story "add text" look (centered, native font, optional colored highlight box behind the words), or the caption-under-post look. Match placement and type to whichever IG surface you're mimicking.
- The hook is the top line and does the scroll-stopping.

### 3 · The copy (native register)
- Caption voice: lowercase energy, contractions, line breaks that pace like a real caption, at most a couple of emoji used the way a person uses them.
- If it's a listy caption, one point per line with visible breaks — never a paragraph.

## Craft rules (priority order)

1. **Match the exact IG treatment.** Right font, right placement, right highlight-box style. Off-platform styling breaks the disguise instantly.
2. **Caption voice, not headline voice.** Write it like a person captioning their own post — casual, specific, a little imperfect.
3. **Hook is the top line.** First line stops the scroll; the rest earns the read. No throat-clearing.
4. **One idea per line; breaks do the pacing.** Especially for listy copy.
5. **Feels organic first, sells second.** The brand/product enters late and lightly; the read is bought by feeling native.
6. **Specificity is credibility.** Real numbers, real phrasing. No absolutes, no ad-speak.
7. **Emoji like a person,** not a decorative row. One or two, meaningful.
8. **Banned:** headline-voice copy, off-platform fonts/placement, "designed to," "seamless," "solutions," decorative emoji rows, and any line that reads like a banner.

## Length caps

| Element | Cap |
|---|---|
| Hook (top line) | ≤12 words |
| Body/caption | 1–5 short lines, each ≤12 words |
| Emoji | ≤2 total, meaningful |
| Brand mention | 1, late and light |

## Build steps

1. Read the brief: angle, persona, moment.
2. Choose which IG surface to mimic (story add-text vs caption) and match its exact type treatment.
3. Write the hook top line first; make it native and scroll-stopping.
4. Draft the body in caption voice; one idea per line.
5. Place the brand late and light.
6. Register + length pass (rules 1–8).
7. Claims pass on any number.
8. Design handoff: exact IG font/placement/highlight-box; UGC-style base image; text legible and native.
9. Deliver: hook line, body lines in order, brand line, IG-styling note (which surface/treatment), claims flags.

## QA checklist
- [ ] Styling matches a real IG text treatment (font, placement, highlight box)
- [ ] Copy is caption voice, not headline voice
- [ ] Hook is the top line and stops the scroll
- [ ] One idea per line; breaks pace the read
- [ ] Brand enters late and light; ≤2 meaningful emoji
- [ ] Any number real; no absolutes/banned phrases
- [ ] Passes the "would scroll past as organic" test at thumb size
