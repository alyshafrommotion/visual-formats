# Instagram Text Overlay Format — Implementation SOP

## Reference examples (look here first)

- **Reference examples:** They sit in this same folder, right next to this SOP.
- This SOP lives in this folder, so the example creatives sit next to it.

**Whenever this SOP is triggered or referenced, open this folder and study the examples first** — the exact IG type treatment, where the text sits, how organic the copy reads, and how stickers/overlays are used (see `loop_instagram-text-overlay` for an image sticker, `spacegoods_instagram-text-overlay-2` for a link-sticker CTA, and `spacegoods_instagram-text-overlay-1` / `natural-cycles_instagram-text-overlay-1` for an overlaid screenshot).

## What this format is

An ad that wears Instagram's own text styling — the story/caption/"add text" look, native fonts, highlight boxes — over a **selfie, POV, or lifestyle shot** that reads like something a person would post to their own story. It works because it borrows the platform's native visual grammar, so the ad slips into the feed as content and gets read before the guard goes up.

It can also carry native story elements: a **link sticker** (the IG story link CTA), an **image sticker**, and **overlaid screenshots or images**. The single thing it can't have is a **comment-response (question) sticker** — a question sticker + reply is the comment-response format, not this one.

Strongest for **hook-led statements, relatable/POV lines, listy value in the caption, and top-of-funnel scroll-stoppers** where feeling native buys the read.

The one property to protect: **native IG text carries the message, over an organic-looking story base, with no question sticker.**

## Inputs

Expect a **messaging angle** (the statement or hook), persona and moment, and VOC for phrasing. The angle sets the message; VOC gives it native voice; this SOP governs the IG styling, stickers/overlays, and the copy register.

## Anatomy — the layers

### 1 · The base (native story shot)
- A selfie, POV, or lifestyle shot that looks shot-on-phone, like someone's own story. Not studio.

### 2 · The IG text treatment (the format)
- Instagram's own text conventions: the story "add text" look (native font, optional colored highlight box), or the caption placement. The hook is the top line and does the scroll-stopping.

### 3 · Native stickers / overlays (optional)
- **Link sticker:** the native IG story link as the CTA.
- **Image sticker:** a native image sticker supporting the point.
- **Overlaid screenshot or image:** drop a screenshot or photo on the story (a review, a text, a chart) — still this format, as long as native IG text is carrying the message and it isn't a comment screenshot acting as the whole ad.
- **Never** a comment-response/question sticker.

### 4 · The copy (native register)
- Caption voice: lowercase energy, contractions, line breaks that pace like a real caption, at most a couple of emoji used the way a person uses them.
- If it's a listy caption, one point per line with visible breaks — never a paragraph.

## Craft rules (priority order)

1. **Match the exact IG treatment.** Right font, right placement, right highlight-box style. Off-platform styling breaks the disguise instantly.
2. **Native text carries the message.** Stickers and overlays support it; they don't replace the IG-styled text as the vehicle.
3. **Caption voice, not headline voice.** Write it like a person captioning their own post.
4. **Hook is the top line.** First line stops the scroll; the rest earns the read.
5. **One idea per line; breaks do the pacing.**
6. **Use stickers the native way.** A link sticker as the CTA, an image sticker or overlaid screenshot as support — placed like a real person would, not as a designed button.
7. **No comment-response/question sticker.** If the idea needs a Q&A question sticker, it's a different format.
8. **Feels organic first, sells second.** Brand/product enters late and lightly.
9. **Specificity is credibility.** Real numbers, real phrasing. No absolutes, no ad-speak.
10. **Banned:** headline-voice copy, off-platform fonts/placement, a question sticker, a comment screenshot used as the whole hero, "designed to," "seamless," "solutions," decorative emoji rows, any line that reads like a banner.

## Length caps

| Element | Cap |
|---|---|
| Hook (top line) | ≤12 words |
| Body/caption | 1–5 short lines, each ≤12 words |
| Emoji | ≤2 total, meaningful |
| Brand mention | 1, late and light |

## Build steps

1. Read the brief: angle, persona, moment.
2. Choose which IG surface to mimic (story add-text vs caption) and match its exact type treatment.
3. Pick the base: selfie, POV, or lifestyle shot that reads organic.
4. Write the hook top line first; make it native and scroll-stopping.
5. Draft the body in caption voice; one idea per line.
6. Add native stickers/overlays only if they help: link sticker CTA, image sticker, or overlaid screenshot — never a question sticker.
7. Place the brand late and light.
8. Register + length pass (rules 1–10). Claims pass on any number.
9. Design handoff: exact IG font/placement/highlight-box; UGC-style base; any sticker/overlay placed natively; text legible.
10. Deliver: hook line, body lines in order, brand line, IG-styling note (surface/treatment), sticker/overlay note, claims flags.

## QA checklist
- [ ] Native IG text carries the message (font, placement, highlight box)
- [ ] Base reads like an organic selfie/POV/lifestyle story
- [ ] Any sticker/overlay used natively (link sticker, image sticker, screenshot) — and no comment-response/question sticker
- [ ] Copy is caption voice, not headline voice; hook is the top line
- [ ] One idea per line; brand late and light; ≤2 meaningful emoji
- [ ] Any number real; no absolutes/banned phrases
- [ ] Passes the "would scroll past as organic" test at thumb size
