# Yapper Format — Implementation SOP

## Reference examples (look here first)

- **Brain location:** `/agent/brain/2. ideation/visual-formats/yapper/`
- This SOP lives in that folder, so the example creatives (videos) sit next to it.

**Whenever this SOP is triggered or referenced, open that folder and watch the examples first** — the hook speed, the pacing/cut rhythm, the energy level, and how the product lands without breaking momentum.

## What this format is

A creator talking fast and direct to camera, carrying the ad on the strength of the script and their delivery — no b-roll crutch, minimal setup. "Yapping": a confident, rapid monologue that feels like a friend who cannot wait to tell you something. It works because energy plus a tight script holds attention, and because direct address feels like a real recommendation.

Strongest for **hook-led persuasion, myth-busting, "here's why you need this," relatable rants, and TOF scroll-stoppers.** Depends entirely on a strong hook and a script written for the mouth, not the page.

The one property to protect: **it has to sound spoken and stay high-energy** — the second it reads like written copy or the pace sags, viewers scroll.

## Inputs

Expect a **messaging angle** (the argument), persona and awareness stage, VOC for phrasing, and claim facts. The angle sets the case; VOC gives it spoken voice; this SOP governs the script structure and delivery notes.

## Anatomy — the beats

### 1 · The hook (0–3s, sometimes longer)
- The first line is a fast, punchy scroll-stopper: a hot take, a callout, a promise, or a "stop scrolling if…" No intro, no "hey guys."
- **A text overlay headline sits on screen for at least the first 3 seconds** (sometimes longer), separate from whatever the creator is saying out loud. Examples: "caffeine tolerance... let's talk about it," "started taking @heights vitals." It gives the viewer context for what they're about to watch before the verbal hook has had time to land.
- **This headline does one of two jobs, depending on the verbal hook:**
  - If the verbal hook is already a direct, punchy scroll-stopper, the text headline reinforces it as a **second hook**, context stacked on top of the spoken line.
  - If the verbal hook is more conversational/story-opening rather than a direct promise or callout, the text headline becomes the ad's **real direct-response hook**, doing the "stop scrolling because of this" job the verbal line isn't doing on its own.
- Either way, the headline should read like a caption a real person would slap on their own video, not ad copy, matching the same spoken-register rules as the VO.

### 2 · The rapid case
- 2–4 quick beats that build the argument, each landing a single point, delivered fast with momentum. Pattern interrupts (a rhetorical question, a "but here's the thing") keep the pace.

### 3 · The product turn
- Product enters as the payoff of the argument, once, mid-to-late, without killing the energy. It's the answer, not an interruption.

### 4 · The ask
- One fast, warm CTA. Singular. In the creator's voice.

## Script / delivery rules (priority order)

1. **Write for the mouth.** Dictate it out loud, transcribe, trim. Read every line aloud; rewrite anything you stumble on. If it can't be said fast, it's the wrong line.
2. **Hook in the first 3 seconds** — punchy, specific, no intro.
3. **Always plan the text overlay headline alongside the verbal hook, not as an afterthought.** Decide together whether the verbal line is already direct (headline reinforces it) or conversational (headline carries the direct-response job instead). Never leave the ad with neither line doing that job.
4. **Momentum is the format.** Short sentences, fragments, pattern interrupts. Cut anything that slows the pace.
5. **One point per beat.** Don't stack; keep each beat a single clean hit.
6. **Spoken register:** contractions, CAPS on one stressed word, sentences starting with "And/But/So," enthusiasm doubling ("so, so good"). 2–4 of these per script, never zero, never all. Applies to the text overlay headline too, it should read like a caption, not a tagline.
7. **Specificity is credibility.** Real numbers, real phrasing. No absolutes; skeptics screenshot them.
8. **Product named the way a person hypes a thing they love,** once, as the payoff. Two mentions max on warm retargets.
9. **Energy carries it, but the script wins it.** Don't rely on the creator to save flat writing.
10. **Banned:** "hey guys," slow intros, written-register sentences, "designed to," "seamless," "solutions," absolutes, and any beat that stalls momentum.

## Length caps

| Element | Cap |
|---|---|
| Hook | 1 line, ≤10 words, in the first 3s |
| Text overlay headline | ≤1 short line, on screen for at least the first 3s (can run longer) |
| Beats | 2–4, one point each |
| Total runtime | 12–30s |
| Sentences | short, spoken-length; ≤12 words |
| Product mentions | 1–2, as the payoff |
| Ask | 1 sentence, 1 action |

## Build steps

1. Read the brief: angle, persona, awareness stage.
2. Pull VOC for spoken phrasing; mark the sharpest line for the hook.
3. Write the hook first; make it fast and specific.
4. Write the text overlay headline alongside it, deciding whether it reinforces a direct verbal hook or carries the direct-response job itself for a more conversational verbal opener.
5. Script 2–4 rapid beats with pattern interrupts; one point each.
6. Place the product as the payoff; write the one-line ask.
7. Dictate-transcribe-trim; read-aloud pass.
8. Register + claims pass (rules 1–10; validate every number).
9. Production handoff: tight framing, direct eye-line, punchy cut rhythm, captions on, text overlay headline placed and timed, high energy sustained end to end.
10. Deliver: hook line, text overlay headline, VO script by beat, product payoff line, ask, delivery/pacing notes, claims flags.

## QA checklist
- [ ] Hook lands in the first 3s; no intro
- [ ] Text overlay headline present for at least the first 3s and doing a clear job (reinforcing the verbal hook, or carrying the direct-response hook itself)
- [ ] Written for the mouth; passes read-aloud at speed
- [ ] Momentum sustained; one point per beat; pattern interrupts present
- [ ] 2–4 spoken-register artifacts; not zero, not all
- [ ] Product enters once as the payoff without killing energy
- [ ] One fast ask; every number validated; no absolutes/banned lines
