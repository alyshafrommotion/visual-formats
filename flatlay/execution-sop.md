# Flatlay Format — Implementation SOP

## Reference examples (look here first)

They sit in this same folder, next to this SOP. **Open the folder and study the example first** — the overhead angle, the arrangement, and how minimal the copy is.

## What this format is

A static shot from directly overhead of the product(s) arranged flat on a clean surface — a styled flat lay, often showing the full color/variant range. It works because a clean, well-styled overhead spread is aesthetic, scroll-stopping, and shows range/abundance at a glance.

Strongest for **range/variety moments, seasonal drops, gifting, aesthetic/lifestyle brands, and "collect them all" energy.**

The one property to protect: **the arrangement reads clean and intentional from directly above** — messy or off-angle kills it.

## Inputs

Expect a **messaging angle** and the products/variants to feature. The angle sets the idea (range, gifting, new drop); this SOP governs the styling.

## Anatomy

1. **The overhead arrangement:** products laid flat, styled (fan, grid, rows), balanced.
2. **The surface:** clean, neutral, uncluttered.
3. **Minimal copy:** one short line if any ("Get one in every color").
4. **Brand + optional CTA.**

## Build rules (priority order)

1. **Shoot/compose straight overhead.** Consistent angle, even lighting, no perspective skew.
2. **Style the arrangement intentionally** — fan, grid, or rows; balanced spacing.
3. **Clean neutral surface** so the products pop.
4. **Show the range** when variety is the point (colors/variants together).
5. **Keep copy minimal** — the visual leads.
6. **Real products; honest.** No absolutes / banned phrases.

## Length caps

| Element | Cap |
|---|---|
| Copy line | ≤6 words (optional) |
| CTA | 0–1 |

## Build steps

1. Read the brief: angle, products/variants to feature.
2. Choose the arrangement (fan/grid/rows) and a clean surface.
3. Style it balanced; shoot/compose straight overhead with even light.
4. Add minimal copy + brand (+ CTA if needed).
5. Claims pass (honest; validate any numbers).
6. Legibility/aesthetic check at thumb size.
7. Deliver: arrangement note, surface/lighting direction, copy, brand/CTA.

## QA checklist
- [ ] Straight-overhead angle, even lighting, no skew
- [ ] Intentional, balanced arrangement on a clean surface
- [ ] Range shown when variety is the point
- [ ] Minimal copy; brand present; honest; no absolutes/banned phrases
