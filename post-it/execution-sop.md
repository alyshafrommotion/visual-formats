# Post-it Format — Implementation SOP

## Reference examples (look here first)

- **Brain location:** `/agent/brain/2. ideation/visual-formats/post-it/`
- This SOP lives in that folder, so the example creatives (images and videos) sit next to it.

**Whenever this SOP is triggered or referenced, open that folder and study the examples first** — how much is written on the note, the handwriting style, and how the note sits against the product/scene.

## What this format is

A handwritten sticky note — or handwritten scrawl/arrow annotation — placed over a product shot, packaging, or lifestyle image. The handwriting signals a real person left a real message: a reminder, a confession, a tip, a hype note. It works because handwriting reads as human and immediate, and because a note "left" on a product feels like insider advice, not an ad.

Strongest for **reminders/nudges, a single strong benefit, a personal tip, urgency (a note that says "don't forget"/"do this"), and warm audiences.** Best when the message is short enough to genuinely fit on a note.

The one property to protect: **the note must read like a person handwrote it in a hurry** — short, casual, one thought. A paragraph of neat handwriting fools no one.

## Inputs

Expect a **messaging angle** (the one thing to say), persona and moment, and any VOC that gives you the phrasing. The angle sets the message; VOC gives it the human voice; this SOP governs the note and its placement.

The note is the whole ad, so the angle must compress to one line. If it can't, it's the wrong format for that angle.

## Anatomy — the layers

### 1 · The base image
- Product, packaging, or a lifestyle scene the note comments on. Real, everyday, not a glossy render.
- Leave a clean surface where the note lands (the product, a fridge, a mirror, a box).

### 2 · The note (the format)
- A sticky note, torn paper, or direct handwritten annotation with an arrow.
- **One thought, handwritten register:** a reminder, a tip, a reaction, a nudge. Contractions, dashes, an underline for emphasis, maybe a doodle arrow.
- If multiple notes, each is one line and they read as a quick stack, not a paragraph.

### 3 · Optional printed anchor
- A small printed headline or CTA elsewhere in the frame can carry the offer, leaving the note purely human. Keep them visually separate so the note stays "real."

## Craft rules (priority order)

1. **One thought per note.** A note argues one thing; it never lists.
2. **Handwritten register.** Casual, short, contractions, an underline or ALL-CAPS on one word, a dash, a doodle. It should look dashed-off.
3. **Say it like a person leaving a note,** not a brand writing a caption. "don't overthink this one" beats "Simplify your routine."
4. **Short enough to actually fit.** If the designer has to shrink the handwriting to cram it, the copy is too long — that's the length check that can't be argued with.
5. **Specificity where it helps,** but a note is allowed to be a feeling or a nudge more than a spec. If a number is used, make it real.
6. **Brand stays mostly off the note.** Let the note be human; put the brand/offer on the printed anchor or once, casually, in the note.
7. **Banned:** typeset-perfect "handwriting," full sentences that read like ad copy, "designed to," "seamless," "solutions," and any note longer than a real sticky.

## Length caps

| Element | Cap |
|---|---|
| Single note | 1 thought, ≤12 words, ≤2 short lines |
| Note stack (if used) | ≤3 notes, each ≤8 words |
| Printed anchor/CTA | ≤8 words |

## Build steps

1. Read the brief: angle, persona, moment.
2. Compress the angle to one note-length thought; pull the phrasing from VOC.
3. Choose the base image and the surface the note lands on.
4. Write the note in handwritten register; decide if a printed anchor carries the offer.
5. Register + length pass (rules 1–7; confirm it fits without shrinking).
6. Claims pass on any number used.
7. Design handoff: believable handwriting, note placed where a person would stick it, arrow/doodle if it helps, printed anchor kept visually separate.
8. Deliver: note text (and stack if any), printed anchor/CTA, base-image direction, claims flags.

## QA checklist
- [ ] Note is one thought, handwritten register, fits without shrinking
- [ ] Reads like a person left it, not like a caption
- [ ] Base image is real/everyday; note sits where someone would stick it
- [ ] Brand mostly off the note; offer on a separate printed anchor if needed
- [ ] Any number is real; no banned phrases
- [ ] Legible and human at thumb size
