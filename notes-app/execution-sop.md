# Notes App — Execution Guide

## What this format is

A screenshot styled as a real Apple Notes card, chrome and all (back arrow, undo/redo, share, ellipsis), carrying whatever text the ad needs: a single tip, a confession, a quote, a reminder, or one point of a longer list (pair with the `Listicle` format when it's the latter).

It works because a native iOS note reads as something a real person jotted down, not a designed brand asset, which lowers the "this is an ad" guard the same way handwriting does for Post-it, but with a typed, tidy, ownable-by-anyone register instead of a handwritten one.

## Anatomy

1. **The Notes card.** Real or real-looking Apple Notes chrome, cropped tight so the chrome reads clearly and only the relevant text shows.
2. **The text.** Typed register: short, personal, plain. Read like the person actually wrote it in their own notes, not brand copy pasted in.
3. **The base image (optional).** The Notes card can float over a photo (lifestyle, product, plain background) or stand alone against a flat color.

## Craft rules (priority order)

1. **The chrome has to be legible and real-looking.** If it doesn't clearly read as Apple Notes, the disguise doesn't work.
2. **Crop tight to one idea.** Don't show a scrollable wall of text; crop so there's exactly one thing to read.
3. **Typed-personal register**, not marketing copy. Short, plain, a little unpolished.
4. **If used as one point of a list, keep every card in the sequence visually consistent** (same crop style, same chrome position) so the sequence reads as one system.
5. **Banned:** overly designed/branded Notes-card mockups that don't look like a real note, walls of text, marketing phrasing inside the note.

## Length caps

| Element | Cap |
|---|---|
| Text per card | ≤2 short lines, one idea |

## Build steps

1. Write the point/tip/note in plain, personal language.
2. Type it into (or mock up) an Apple Notes card; crop tight, keep the chrome visible.
3. Decide on a base image or flat background if one is needed.
4. If this is one point of a longer sequence, check whether the ad also qualifies as `Listicle` and plan the full sequence together.
5. Deliver: note text, crop/chrome direction, base image direction if used.

## QA checklist
- [ ] Notes chrome is visible and reads as real
- [ ] Cropped to one idea, no wall of text
- [ ] Text reads personal/typed, not like marketing copy
- [ ] If part of a sequence, visually consistent across cards
